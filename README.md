# CardGame
基于 Cocos2d-x 3.17.2 开发的经典纸牌匹配消除游戏，采用 MVC 架构设计，支持完整的游戏流程和无限回退功能。
🎮 游戏简介
这是一款简单有趣的单人纸牌游戏。玩家通过匹配手牌与桌面牌的点数来消除卡牌，目标是消除桌面上所有的牌。游戏操作简单易上手，同时具备完整的回退机制，让玩家可以随时反悔上一步操作。
✨ 核心功能
✅ 卡牌匹配系统：桌面牌与手牌点数相差 1 即可匹配消除
✅ 手牌翻牌替换：从备用牌堆抽取新牌替换当前手牌
✅ 无限回退功能：支持任意步数的操作回退，卡牌原路返回
✅ 流畅动画效果：所有卡牌移动都带有平滑的缓动动画
✅ 竖屏适配：完美适配 1080×2080 竖屏分辨率
✅ 开箱即用：完整项目包含引擎，下载后直接编译运行
🚀 快速开始
环境要求
操作系统：Windows 10/11
开发工具：Visual Studio 2022（推荐）/ 2019
无需额外安装：Cocos2d-x 引擎、Python 2.7 等依赖已包含在项目中
运行步骤
克隆或下载本仓库到本地
打开 proj.win32/CardMatchGame.sln 解决方案文件
在 Visual Studio 顶部选择 Debug 或 Release 配置，平台选择 Win32
点击 本地 Windows 调试器 或按 F5 键
游戏将自动编译并运行
🎯 游戏玩法
游戏开始时，桌面上会显示若干张翻开的牌，底部有一张手牌
点击桌面上任意一张与手牌点数相差 1 的牌，该牌会移动到底部成为新的手牌
当桌面上没有可匹配的牌时，点击备用牌堆抽取新的手牌
点击回退按钮可以撤销上一步操作，支持无限回退
消除桌面上所有的牌即为游戏胜利
匹配规则
点数相差 1 即可匹配，花色不影响
A (1) 只能匹配 2
K (13) 只能匹配 Q (12)
